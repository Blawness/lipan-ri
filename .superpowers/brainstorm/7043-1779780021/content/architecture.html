Arsitektur & Halaman — Ringkasan Desain

Next.js 16 + Drizzle + shadcn/ui — klik tombol untuk lanjut ke detail

Tech Stack

Next.js 16
PostgreSQL
Drizzle ORM
shadcn/ui
Tailwind CSS
NextAuth.js v5

Struktur Halaman

lipan-ri.org
/ Homepage — featured posts, latest news, categories, search
/ [slug] — article detail page
/ category/[slug] — category listing (berita, press-rilis, opini, dll)
/ tentang-kami — profil lembaga, ketua, visi-misi, struktur, legalitas
/ galeri — galeri foto kegiatan
/ kontak — halaman hubungi kami

Data Model (Drizzle Schema)

posts
id, slug, title
content (MDX/HTML)
excerpt, featured_image
category_id, author_id
status, published_at
categories
id, slug, name
description, parent_id
pages
id, slug, title
content, meta_description
updated_at
media
id, url, alt_text
album, uploaded_at
users
id, email, name
role, password_hash
(untuk admin nanti)
